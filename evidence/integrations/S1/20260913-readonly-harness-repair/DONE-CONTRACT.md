# Read-only harness repair done contract

Done means the consumed runner, offline test, and manifest are archived byte-for-byte with their verified historical hashes before either source file changes. Every host PowerShell observation in the corrected runner receives exactly `{SystemRoot, WINDIR}` while the isolated launcher payload retains its distinct eight-key environment contract. ACL and other host subprocess results retain bounded status, signal, structured error, stdout, and stderr before classification.

The corrected runner must fail its old frozen-manifest hash gate before creating the owned root, starting PowerShell, or invoking the launcher. Offline dependency-injected tests must exercise the actual host-call wrapper, environment shape, raw diagnostic preservation, failure precedence, and pre-side-effect old-manifest rejection. No production source, build output, old manifest, intent, result, AppContainer, native helper, ACL, network, model, or provider is touched.

At most two evidence-based implementation corrections are allowed. Every pass runs the focused offline tests, syntax checks, archive hash comparison, and scoped diff check. Independent review is required before completion; this repair supplies no native qualification or new execution authority.
