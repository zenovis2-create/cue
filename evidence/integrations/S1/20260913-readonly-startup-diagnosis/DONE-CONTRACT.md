# Read-only startup diagnosis done contract

Done means a measured report ties the failed windowless attempt timestamp, PID, exit class, executable, environment, standard-handle setup, process attributes, and relevant executable ACL assumptions to exact source lines and retained evidence. It compares those facts with the reviewed model-only launcher and records only narrowly time-bounded Windows Application events for the attempt PID/executable when available.

This unit performs no source edit, native/AppContainer/helper/model/provider/network launch, ACL change, process termination, credential access, or gate retry. At most two diagnostic hypotheses may be recorded, each clearly separated from observed facts. The result must identify one next discriminating experiment or a concrete defect; absent evidence, it must say the cause remains unknown.
