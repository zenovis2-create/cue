# Sanitized environment comparison done contract

Done means one new owned fixture is observed once with the same `runProcessSync`, Windows PowerShell executable, `Get-Acl` argv, timeout, encoding, and output bound as the initial diagnostic, while the child receives exactly two environment keys: `SystemRoot` and `WINDIR`, both bound to the current system root. Raw status, signal, structured error, stdout, stderr, exact environment-key inventory, and a valid-SDDL or precise failure verdict are persisted.

The cap is one host process call. There is no retry, AppContainer launch, native helper, ACL change, network access, model/provider call, or mutation of the frozen probe and initial diagnostic artifacts. The result only discriminates inherited-environment behavior from this two-key sanitized environment; it grants no native-boundary claim or retry authority.
