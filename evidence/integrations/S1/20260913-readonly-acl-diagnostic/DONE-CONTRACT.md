# Read-only ACL diagnostic done contract

Done means one host-only reproduction uses the exact frozen probe `runProcessSync` wrapper, PowerShell executable, argv, timeout, encoding, and output bound against a new owned temporary directory. It durably records bounded `status`, `signal`, structured spawn `error`, `stdout`, and `stderr`, then reports either one nonempty SDDL value or a precise failure class. It launches no AppContainer, changes no ACL, invokes no native helper/model/provider/network endpoint, and never reruns the consumed Unit A probe.

The diagnostic has one reproduction attempt. At most two evidence-based correction hypotheses may be documented. Every implementation pass runs syntax checks and offline injected-result tests covering spawn error, signal, nonzero status, nonempty stderr, empty output, malformed SDDL, and valid SDDL. Only a strictly better measured gate is retained; otherwise the change is reverted or handed back.
