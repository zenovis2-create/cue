## 다음 구현·검증 단위 — batch70

원본 44행과 완료 overlay 23행은 위에 보존한다. 아래는 남은 21행의 다음 조치이며, 이미 완료한 이전 배정 목록을 재실행하는 지시가 아니다.

1. **R03~R05:** 현재 선택 fixture/tool의 카탈로그·바이트 결합과 변경 무효화는 검증했다. 실제 채택 transport별 lifecycle, 배포 연결, transport 자격이 남는다. R06은 현재 선택 fixture/tool의 업데이트 조건으로만 완료다. Gate: 선택 manifest에 대응하는 Cue 계약과 실제 경계 영수증.
2. **S0-01, S1-01~05:** 설치·인증 주체·프로토콜·취소·종료·재시작을 현재 공급자 바이트에 결합한다. Qwen OFF와 출처 불명 Codex SHA 보류를 유지한다. Gate: 각 대상의 독립 측정 및 unsupported/unknown 유지; 합성 evidence로 live 자격을 부여하지 않는다.
3. **S2-02~03, S5-03:** 확정 원장 비용을 관측·평가군에 전달하는 오류와 비용 배분 변조를 교정했다. 실제 공급자 가격·쿼터·최종 청구, 인계 비용 귀속이 남는다. Gate: 동일 request/attempt 원장 총액과 비용 단계 일치, 미확정 비용 누락 0.
4. **S3-01, S3-03:** 실제 Git staging factory와 public driver의 게시·정리 하위 경로를 검증했다. 배포 호스트의 신뢰 저장소 설정과 기본 어댑터 연결, 실제 변경 작업의 정리 정책 및 전체 실행 자격이 남는다. Gate: 승인된 원본·격리 root 결합, 미확정 생성 재채택 0, dirty 정리 실패 시 lease 유지, 실제 완료 증거.
5. **S4-01, S4-05:** 현재 공급자 세션과 외부 영수증의 신뢰 경계·인증·재연결을 검증한다. 기존 실제 Windows crash/Stop 증거는 공급자 청구 확정과 구분한다. Gate: 인증된 현재 receipt와 중복 실행/전송/쓰기 재개 0.
6. **S5-04~05, S5-08, A01, A08:** 고정 dataset/holdout 및 수동 baseline을 실제 승인 예산 안에서 실행하고 네 모드의 품질 하한·목표 개선을 입증한다. Gate: 완전한 비교 cohort, 실제 청구 정산, 단계 회귀·독립 리뷰·릴리스 gate. 현재 전체 출시 not-ready와 성능 개선 not-proven을 유지한다.

추가 코드는 각 단위의 실패 재현과 완료 명령을 먼저 고정하고 작성한다. 외부 사실을 구현용 fixture로 대체하거나 로컬 모델을 자동 재시작하지 않는다.
