## 다음 구현·검증 단위 — batch72

1. **S0/S1 현재 설치본 연결:** 설치 guard의 정확한 descriptor를 보호된 설정·catalog identity 참조에 연결한다. 실행 직전 재측정과 qualification 무효화는 필요하며, version/help를 인증이나 실행 자격으로 승격하지 않는다. 예전 출처 불명 SHA와 현재 서명된 Codex payload를 구분한다.
2. **S3 기본 실행 호스트:** 검증된 native composition에 실제 계정 entitlement, 비용 관측, 불변 대상·요구사항, 독립 verifier principal과 최종 인수 checker를 공급하는 보호된 설정 경로를 구현한다. 준비·승인 fixture와 실제 공급자 workflow 성공을 구분한다.
3. **S1/S4 공급자 관측:** 승인된 실제 호출에 한해 정상/실패/취소/재시작을 검사하고 계정·시도에 결합된 종료/청구 및 외부 효과 receipt를 인증 경로에 연결한다. 로컬 프로세스 종료는 원격 종료·청구 확정을 뜻하지 않는다.
4. **S2/S5 실측:** 승인 예산과 실제 비용 출처가 확보되면 호출·재시도·검증·인계 비용을 정산하고 동결 baseline/holdout에서 네 모드를 비교한다. 누락·unknown을 개선 실적으로 계산하지 않는다.
5. **보류:** Qwen은 사용자 지시에 따라 OFF다. 전체 release는 해당 실제 자격·실측·독립 검토가 끝날 때까지 not-ready다. 상위 checkbox는 원래 조건으로 판정한다.
