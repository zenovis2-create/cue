# Phase 7 — 보고, 주석, 게시 (P7-1 ~ P7-12)

Phase 6까지 대화 표면이 섰다(테스트 112 통과 / 4 스킵).
Phase 7은 **작업 결과가 사람에게 보이는 층**이다.

여기서 가장 위험한 실패는 **승인 없이 밖으로 나가는 것**이다.
게시는 되돌릴 수 없다. 한 번 공유된 것은 회수해도 이미 읽혔다고 가정한다.

## 판정 규칙

- `PASS` — 검사가 실제로 통과.
- `PARTIAL` — 탐지만 되고 강제되지 않음. **PASS 아님.**
- `FAIL` / `SKIPPED`(이유 필수).

**기존 테스트(p1~p6)를 수정하거나 삭제하지 마라.** 단정을 약화시켜 초록불을 만드는 것은 그 자체로 FAIL이다.

**외부 상태를 바꾸지 마라.** 실제 `orca artifacts share` 호출, 실제 게시, 실제 릴레이 전송 금지. 어댑터와 테스트만 만들고, 실기동이 필요한 항목은 SKIPPED로 적어라.

## P7-1 하나의 결과 레코드, 세 렌더링

한국어 요약 / 상세 보고서 / HTML이 **같은 레코드 하나**에서 나온다.

검사: 렌더러 3개가 동일한 `result_record`를 입력으로 받고, 각자 따로 원장을 조회하는 경로가 없다. 레코드를 바꾸면 세 출력이 함께 바뀐다(테스트 1개).

## P7-2 HTML은 고정 안전 컴포넌트

모델이 스크립트를 넣지 못한다.

검사: `<script>`, `onerror=`, `javascript:`, `<iframe>` 주입을 각각 시도하고 렌더 결과에서 제거·이스케이프됨을 확인(각 1개 테스트).
검사: 렌더러가 허용하는 컴포넌트가 **고정 목록**이고, 목록 밖 노드는 렌더 자체가 거부된다. 문자열 치환 필터로 때우지 마라 — 허용 목록 방식이어야 한다.

## P7-3 게시 전 편집 게이트 5단계

`파일·필드 나열 → 비밀정보 스캔 → 미리보기 → 사람 승인 → artifacts share`.

검사: 승인 없이 `orca artifacts share`에 도달하는 코드 경로가 **0개**.
검사: 스캔 테스트 4개 — 토큰 / 키 / `.env` 내용 / 사용자명이 포함된 절대 경로.
검사: 5단계 중 하나라도 건너뛰면 게시가 거부된다(순서 강제 테스트 1개).
**fail-closed**: 스캐너가 오류를 던지면 통과가 아니라 거부다.

## P7-4 설명 표면과 작업 표면 분리

주석은 양쪽 다, 컨트롤은 어느 쪽에도 주입하지 않는다.

검사: 공유 HTML 산출물에 주석 컨트롤·스크립트가 없다.
검사: 대상 페이지 origin에 오버레이를 주입하는 경로가 없다.

## P7-5 v0.1 주석 입력 = 채팅 이미지 + 한국어 텍스트

두 표면 동일. 새 UI 없음.

검사: 이미지 첨부 + 한국어 지시가 태스크로 변환된다 — `work` / `explain` 각각 1개 테스트.

## P7-10 주석에 `surface` 필드

검사: `surface` 없는 주석 레코드는 **거부**된다(빈 문자열도 거부).
검사: `surface: explain`은 artifact id + 버전을, `work`는 page id를 신원으로 쓴다.
검사: 한 레코드가 두 표면을 동시에 가리키는 경로가 없다 — 타입 수준에서 배타적으로(유니온), 런타임 if로 때우지 마라.

## P7-11 `explain` 주석이 승인 경로를 건너뛰지 않는다

검사: 보고서에 달린 주석이 코드 변경을 요구하면 **봉투 판정을 그대로 거친다**. 주석이라는 이유로 우회하는 경로가 없다.

## P7-12 아티팩트 버전이 신원의 일부

검사: 재생성 후에도 옛 주석이 **옛 버전**을 가리킨다. 자동 이관 경로 없음.
검사: 사람이 HTML을 직접 편집하는 경로가 없다 — 원장 수정 후 재생성뿐.

## P7-6 캡처 3종을 한 턴에

`orca screenshot` + `orca snapshot` + `orca tab current --json`.

검사: 세 산출물이 **같은 캡처 id**로 묶인다. 하나라도 실패하면 캡처 전체가 실패(부분 캡처 금지).
어댑터만 만들고 실제 Orca 호출은 주입된 fake로 검증하라.

## P7-7 주석 페이로드 스키마 — page id가 신원, URL은 라벨

검사: URL만으로 페이지를 식별하는 코드 경로가 없다.
검사: **선택자 없는 스크린샷 전용 레코드가 유효**하다(테스트 1개).

## P7-8 주석은 즉시 원장으로, 로컬 스토리지는 비상 백업

`orca storage local get|set` 사용, **`orca eval` 금지**.

검사: 데몬 차단 중 만든 주석이 재연결 시 원장으로 flush된다.
검사: 소스에 주석 저장용 `orca eval` 호출이 **0개**.
