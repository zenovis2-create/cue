## Short launch post

```text
Give AI a goal. Keep control of the work.

Cue is a Windows desktop app for coding tasks with an explicit approval step:
• Describe the outcome.
• Review the workspace and allowed actions.
• Approve, follow progress, and inspect the result.

The 34-second demo shows a real run creating an interactive HTML checklist.

v0.1 is built around file-changing tasks, with documented execution boundaries and limitations. Requires Windows 11 and an authenticated Codex CLI. The app UI is currently Korean; the demo uses English presentation labels.

Watch the demo and try a small task:
https://github.com/zenovis2-create/cue
```

## Keep the promise specific

- Say “isolated workspace actions,” not “the entire app is sandboxed” or “fully offline.” Model communication runs on the host.
- Say “34-second demo,” not “build anything in 30 seconds.” Waiting was edited out.
- Say “recorded result,” not “all output is correct” or “every check passed.” Inspect the output and retain blocked states.
- Say “v0.1 with documented limitations,” not “production-ready” or “security certified.” Existing evidence is bound to its source snapshot.
- Do not advertise nested subprocess workflows or general research-task verification as supported.
