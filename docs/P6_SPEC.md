# Phase 6 — 대화 표면 (P6-1 ~ P6-11)

Phase 5까지 데몬·봉투·강제·감시가 섰다(테스트 99 통과 / 3 스킵).
Phase 6은 **사용자가 실제로 보는 표면**이다.

여기서 가장 위험한 실패는 **프론트도어가 힘을 갖는 것**이다.
대화하는 쪽이 직접 코드를 고칠 수 있으면, 지금까지 만든 봉투·승인·강제가 전부 우회된다.

## 구속력 있는 전제 (바꾸지 마라)

1. **프론트도어는 저능력.** 도구는 두 개(대화, 데몬 API)뿐.
2. **YAML 편집 UI는 v0.1 영구 제외.** 사용자에게 YAML을 보여주지 마라.
3. **한국어 세 줄 + 봉투 한 줄**이 승인 표면이다.
4. **정상 동작 중에는 침묵한다.** 주기적 하트비트 메시지 금지.
5. 통화 환산 금지. 토큰만.

## 환경 주의
Buzz 릴레이/`@cue` 신원 등록은 **외부 시스템 상태를 바꾼다**.
**실제 등록을 수행하지 마라.** 어댑터와 스키마, 그리고 검증 가능한 단위/통합 테스트만 만든다.
실기동 검증이 불가능한 항목은 **SKIPPED + 이유**로 적어라. 위장 PASS 금지.

## 만들 것

### P6-1 `@cue` 전용 신원 (설계 + 어댑터)
- `@cue` 신원 설정 구조와 어댑터를 정의한다. **실제 계정 생성은 하지 마라.**
- 검사: 신원 설정이 없으면 fail-closed(아웃바운드 전송 시도 자체가 없다).

### P6-2 프론트도어는 저능력 ★
- 프론트도어 세션에서 **`codex`/`orca`/파일 편집 도구가 거부된다.**
- **`running` 전이를 만드는 유일한 경로가 데몬 API다.**
- 검사: 프론트도어 도구 허용목록이 정확히 2개. 그 밖의 도구 요청은 거부.
- 검사: 소스 검사 — 프론트도어 모듈에서 spawn/기동 경로에 도달할 수 없다.

### P6-3 아웃바운드는 데몬 자신이 보낸다
- 검사: **프론트도어 세션을 종료해도 결과 메시지가 도착한다**
  (전송 주체가 데몬임을 단정 — 프론트도어 핸들 없이 전송이 성립).

### P6-4 `channel_id` + 승인 시점에 고정된 `thread_root`
- 검사: **다른 채널에서 말을 걸어도 결과는 승인된 스레드로 간다.**
- `thread_root`는 승인 시점에 고정되며 이후 변경 불가(불변 단정).

### P6-5 데몬이 동시 채널 요청을 직렬화
- 검사: 두 채널 동시 요청이 순서대로 처리되고 **상태가 섞이지 않는다.**

### P6-6 한국어 세 줄 + 봉투 한 줄 ★
- 검사: **채팅 출력 문자열에 YAML이 없다**(출력 문자열 테스트).
- 검사: **YAML 편집을 여는 UI 경로가 없다**(소스 검사).
- 세 줄 = 무엇을/어디까지/무엇을 안 건드림. 봉투 한 줄은 사람이 읽는 요약.

### P6-11 승인 화면에서 자율성 수준 선택
- 봉투 한 줄 옆에 수준 표시, **기본 ③**.
- 검사: 아무것도 안 고르면 ③으로 시작한다.
- 검사: **선택한 수준이 그 실행의 원장 레코드와 일치한다**(P5-12 연동).

### P6-7 사전 인터뷰 최대 3문, 봉투를 바꾸는 질문만 ★
- 검사: **4번째 질문 경로가 없다.**
- 검사: **봉투를 바꾸지 않는 질문은 생성되지 않는다.**
- 검사: 불확실성은 질문이 아니라 **봉투 축소 + `안 건드릴 것` 한 줄**이 된다.

### P6-8 정상 동작 중 침묵
- 검사: **주기적 하트비트 메시지를 보내는 코드 경로가 없다**(소스 검사 + 타이머 테스트).
- 상태 변화(막힘/완료/승인 필요)에서만 말한다.

### P6-9 건강 벡터 한 문장을 작업 수락 전에
- 검사: **Orca를 끈 상태로 작업을 요청하면 무엇이 죽었는지 먼저 답한다**
  (그리고 작업을 수락하지 않는다).

### P6-10 `buzz canvas`를 쓴다면 작성자는 데몬 하나
- 검사: **두 번째 작성 경로가 없다.** 캔버스는 주석 저장소가 아니다.

## 절대 규칙
1. **기존 99개 테스트를 깨지 마라.** `p1*`~`p5*` 테스트의 단정을 약화·삭제·skip 금지.
2. **증거 없이 완료 주장 금지.** 항목마다 실제 테스트 출력.
3. 판정은 `PASS|PARTIAL|FAIL|SKIPPED`. **위장 PASS가 진짜 실패다.**
4. 작업 범위는 `C:/Users/User/cue/daemon`. 금지: `D:/AI2_WIN/AI-backup-20260505/tactics`.
   `probes/`, `evidence/P1..P5/` 기존 파일 수정 금지. **`daemon/evidence/` 만들지 마라.**
5. **외부 시스템(Buzz 릴레이, 실제 채널, 실제 계정) 상태를 바꾸지 마라.**
6. 자격 증명 값 출력 금지.
