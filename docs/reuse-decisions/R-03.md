# R-03 — 로컬 모델 endpoint client 사전 심사

조사일: 2026-09-11 · 단계: S0 → S1 · 상태: **defer (단일 요청 실험 대상 선정)**

## 계약·완료 기준

로컬 모델은 모델 전용 M 경로다. 입력은 승인된 endpoint identity, canonical model ID, 요청/시도 ID, 텍스트, 출력·시간 상한, AbortSignal이다. 결과는 텍스트/종료 사유/관측 usage와 client cancel, provider stop의 개별 상태다. 도구 호출 제안은 데이터이며 실행 권한이 아니다. 서버 실행·모델 download/pull·클라우드 fallback·사용자 설정 변경은 이 client의 권한 밖이다.

`host-codex-runtime.ts`의 워커 실행/종료 보증은 HTTP 서버에 자동 적용하지 않는다. `adapters/registry.ts` 등록은 모델 존재나 자격의 증거가 아니다. 로컬 전용은 단순 hostname 문자열을 신뢰하지 않고 승인된 주소/포트·redirect 금지·실제 연결 대상과 모델 identity를 확인해야 한다. 원격 인증을 로컬 요청에 재사용하지 않는다. 추론 프로세스가 다른 계정/클라우드로 넘기는지는 서버 자격 검사에서 따로 판정한다.

완료 기준: 고정 후보·직접 구현 대안·제한·실험 명세·독립 검토 기록. 조사 1회, 실험 1회와 새 가설 수정 최대 2회. 현재 설치/모델 호출/실험 없음. 입력 hash·시간/자원·명령 exit code는 미측정이다.

Ollama의 stream AbortController는 response를 기다리기 전에 생성되지만 iterator는 response 후 반환된다. 따라서 헤더 전 취소는 공개 iterator만으로 해결되는지 확인이 필요하며, custom fetch와 Cue signal 결합 실험 대상으로 둔다. 서버의 실제 추론 종료는 JS abort 호출만으로 확정하지 않는다. [stream 경로](https://github.com/ollama/ollama-js/blob/9c92b18d4026f5345ff7950f15216372b23401a1/src/browser.ts), [iterator·JSON 처리](https://github.com/ollama/ollama-js/blob/9c92b18d4026f5345ff7950f15216372b23401a1/src/utils.ts)

usage는 서버가 실제 반환한 token count만 기록하고 빠진 필드는 unknown이다. 로컬 전력/하드웨어 비용을 0으로 대입하지 않는다. 알 수 없는 JSON 필드는 기능 지원의 근거가 아니며 알려진 terminal 형식을 검증한다. EOF 중단은 완료가 아니다. 모델명을 사용자 별칭에서 추정하지 않고 서버 목록/상세 응답과 지문을 매핑한다.

## 고정 소스·라이선스·유지 조건

- Ollama: [manifest](https://github.com/ollama/ollama-js/blob/9c92b18d4026f5345ff7950f15216372b23401a1/package.json), [MIT 원문](https://github.com/ollama/ollama-js/blob/9c92b18d4026f5345ff7950f15216372b23401a1/LICENSE). 소스 snapshot과 실제 npm tarball 버전/무결성은 구분한다. client 라이선스는 서버나 모델 weight의 라이선스를 대신하지 않는다.
- OpenAI SDK: [manifest](https://github.com/openai/openai-node/blob/3c4e4d26e3aebd422bc73787e4fcbd1773607785/package.json), [Apache-2.0 원문](https://github.com/openai/openai-node/blob/3c4e4d26e3aebd422bc73787e4fcbd1773607785/LICENSE). 조건과 retry 유의점은 R-01과 같다.

저작권/허가 고지를 보존하고, package tarball의 제3자 고지·설치 동작을 실험 전에 심사한다. 두 후보 테스트 스크립트 존재만 확인했으며 실행/현재 CI/취약점 부재는 미확인이다. public API로 감싸고 upstream 내부 전역 상태나 agent loop는 편입하지 않는다. 업데이트는 고정 fixture·정지/identity 자격 재검증 후 별도 적용한다. 외부 patch 요구량은 연결 후 측정한다.

## 직접 구현 대비 비용과 탈출 경로

같은 단일 텍스트 요청 범위에서 fetch는 URL·signal 통제가 단순하지만 NDJSON/SSE decoder·스키마/오류 검증을 Cue가 유지해야 한다. Ollama SDK는 native 기능 매핑을 줄여주지만 pre-header cancellation·공유 abort·배포 버전 심사가 필요하다. OpenAI SDK는 R-01과 공유할 수 있지만 서버별 호환성 검사를 줄여주지는 않는다. 실제 투입 시간이나 절감률은 아직 없다. 연결/patch/test/update 노력과 취소 실패를 같은 fixture로 비교해 결정한다. 심사·수정 비용이 단일 endpoint 구현보다 커지면 native fetch 경로를 유지한다. 이 판단은 더 넓은 API 전체 직접 구현을 정당화하지 않는다.

## 다음 실험·미확인 사항

1. 실제 모델 없이 disposable loopback HTTP fixture에서 native NDJSON과 compatible SSE의 정상 terminal/usage를 검사한다. raw fixture hash와 서버 request count를 기록한다.
2. UTF-8 분할, JSON 파손, line/총출력 상한 초과, 에러 terminal, 잘못된 model identity, usage 누락/추가 필드를 검사한다. 실패/불명확 응답의 completed 전환 0.
3. 헤더 전·응답 중·병렬 2개 중 하나 취소를 검사한다. 취소한 요청의 socket close와 다른 요청 유지, 전체 기한, 자동 retry 0을 측정한다.
4. 비loopback 주소·redirect·미승인 포트·환경 proxy·URL 인증정보를 거부하는 경계를 검사한다. 사용자 홈/모델 download/자식 프로세스 생성 0을 확인한다.
5. Cue 재시작에서 미완료 요청의 재송신 0과 provider stop unknown 유지, 원장 attempt 중복 제거를 검사한다.
6. `evidence/integrations/S1/<run-id>/reuse/R-03/`에 명령/exit code·hash·시간·자원을 저장한다. 그 후 실제 승인된 로컬 서버/모델 지문, 메모리 부족, 실제 추론 정지·클라우드 전환 부재를 측정한다. fixture 통과를 실물 지원 완료로 표시하지 않는다.

## 2026-09-11 실험 추가 기록

사전 심사 뒤 native fetch 기준선에서 NDJSON 정상·usage unknown·파손·부분·tool 거부와 공통 HTTP 취소 경계를 검사했다. 합계 18개 통과의 명령/실패 수정/hash/한계는 [공유 실험 결과](../../evidence/integrations/S1/20260911-transport/reuse/R-01/RESULT.md)에 있다. 실제 Ollama 프로세스나 모델을 실행한 것이 아니며 위 미실행 문구는 사전 심사 시점 기록이다.
