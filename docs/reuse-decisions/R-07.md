# R-07 — Windows 모델 경계의 실제 상태 관측

2026-09-11 · 결정: MXC 전체 편입 보류, 좁은 Windows API 관측은 Cue에서 구현 예정. 설치·코드 복사·정책 변경 없음.

입력은 호스트가 소유한 child/Job handle, PID와 시작 시각, 생성한 package SID다. 출력은 실제 Job 제한/구성원, 실제 AppContainer token/SID/capabilities, loopback exemption 조회와 통제된 시도의 관측이다. API 실패·신원 변경·종료 경합은 unknown이다. 고정된 설정값이나 Node UNKNOWN/ETIMEDOUT을 성공 증거로 삼지 않는다. 전역 firewall/audit/exemption 변경은 범위 밖이다.

## 비교

| 후보 | 확인한 기능 | 결정 |
| --- | --- | --- |
| Microsoft MXC AppContainer backend | Job 종료/active process 조회, suspended launch, 명시적 handle/env | 관측 패턴 참고. 현재 Cue에 이미 있는 launch 순서를 다시 도입하지 않음 |
| Cue의 좁은 native observer | 실제 소유 handle에서 Job 제한과 token을 직접 조회 | 다음 실험 대상. 아직 구현/실측되지 않음 |

MXC 고정 SHA는 `c096d77f401556f79b9b4c1365b21b21237dcb43`. [루트 MIT 라이선스](https://github.com/microsoft/mxc/blob/c096d77f401556f79b9b4c1365b21b21237dcb43/LICENSE.md), [native backend 의존성](https://github.com/microsoft/mxc/blob/c096d77f401556f79b9b4c1365b21b21237dcb43/src/backends/appcontainer/common/Cargo.toml#L16-L34)을 조사했다. Rust/windows bindings와 여러 내부 workspace 패키지가 필요하므로 현재 Node/PowerShell 경계의 작은 대체 부품으로 바로 편입하기 어렵다. 실제 빌드·전이 고지·배포 바이너리 검증은 수행하지 않았다.

[Job 구현](https://github.com/microsoft/mxc/blob/c096d77f401556f79b9b4c1365b21b21237dcb43/src/backends/appcontainer/common/src/job_object.rs#L318-L364)은 active process가 0인지 조회해 정리한다. 조사한 backend는 kill-on-close를 설정하지만 Cue의 activeProcessLimit=1 확인을 대신하지 않는다. 실제 제한 readback이 추가로 필요하다. 조사 범위에서 Cue에 필요한 token/SID/capability·loopback exemption 결과 DTO는 찾지 못했다. 이 부재 판단은 검색 범위의 결과이며 프로젝트 전체에 대한 보증이 아니다.

[Windows 네트워크 제한 설명](https://github.com/microsoft/mxc/blob/c096d77f401556f79b9b4c1365b21b21237dcb43/sdk/node/README.md#L70-L82)은 host allow/block 목록 미구현을 명시한다. [WinHTTP 정책 helper](https://github.com/microsoft/mxc/blob/c096d77f401556f79b9b4c1365b21b21237dcb43/src/host/wxc_winhttp_proxy_shim/src/proxy_policy.rs#L324-L350)는 상승 권한을 요구하는 변경 기능이므로 이번 읽기 관측 후보로 채택하지 않는다.

## 다음 실험과 한계

현재 native fresh DACL 실측은 profile/TEMP EPERM, guardian 강제 종료 정리는 독립 통과했다. 실패했던 ACL 시점 가설을 다시 실행하지 않는다. 남은 Job/token 관측은 `next-observation-contract.md`에 정의한 입력으로 최초 실험 및 진단 후 최대2회 수정, 신원/원본결과/hash/cleanup을 보존하고 독립 검토한다. 예상 비용은 작은 observer가 전체 Rust backend 연결보다 낮다는 정성적 판단이며 인일/효율 실측은 없다. 이 기록은 채택 완료나 M 자격 PASS가 아니다.

조사자: `model_boundary_reuse` (read-only librarian), 범위 정정 후 delta 보고를 부모가 정리했다. 외부 코드를 복사한다면 별도 고지·patch·버전 업데이트·Windows 회귀 게이트가 필요하다.

후속 구현: Cue native observer가 실제 child token/SID/capabilities·Job 제한/구성원·loopback 예외를 조회하고 독립 관측/강제 종료2개 검사를 통과했다. 추가 Job completion-port 원인 관측도 독립2개 검사를 통과했다. `evidence/integrations/S1/20260911-model-boundary/review-observation.md`, `review-process-limit.md` 참조. MXC 코드는 복사하지 않았다. WFP 수집 상태 읽기는 권한 오류로 미확인이며 네트워크 drop·전체 모델 자격을 통과로 처리하지 않았다.

## 후속 구현 상태

초기 비교의 미구현 표시는 당시 상태다. 후속 Cue native 관측과 고정 qualification harness는 실제 Windows 검사를 거쳐 독립 검토됐다(evidence/integrations/S1/20260911-fixed-qualification/review.md). MXC 전체 코드 편입은 계속 보류하며, collector와 현재 subject에 대한 M 자격 발행은 아직 별도다.
