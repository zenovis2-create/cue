### 실행한 최소 대안 실험

위 TeamAI serializer 실험은 여전히 미실행이다. 대신 외부 타입/권한 전달을 제한하는 Cue native 계약을 [role-contract.mjs](../../scripts/reuse/role-contract.mjs)와 [테스트](../../scripts/reuse/role-contract.test.mjs)로 분리 구현했다. 입력은 id/role/instructions와 optional model.canonicalId만 받으며 역할은 planner/implementer/verifier다. canonical ID는 문자열 형식만 확인하며 실제 설치/지원/자격을 증명하지 않는다. 결과는 제한된 JSON이며 TOML/Markdown 배포와 모델 선택 기능은 포함하지 않는다.

독립 contracts_review가 발견한 role ID의 경로 구문 허용을 수정했다. role ID는 영숫자로 시작하는 영숫자/점/밑줄/하이픈만 허용하며 slash/backslash/colon과 dot-only를 거부한다. model canonical ID의 namespace 구분 문자는 데이터로만 유지하고 파일 경로로 사용하지 않는다. 경로형 ID 회귀 fixture를 추가했다.

### S2 최종 disposition — 2026-09-12

엄격한 메모리 내 RoleSpec formatter에 한해 **Cue direct native 구현을 제한적으로 채택**한다. 채택 대상은 위 fixture로 검증한 `parseRole`/`serializeRole` 계약뿐이다. 결과는 inert role data이며 모델 선택, tool 추가, permission 부여, 파일 쓰기, 설치 또는 실행 권한이 없다. `canonicalId`도 문자열 데이터일 뿐 현재 host의 자격·admission을 대신하지 않는다.

이 범위에서는 TeamAI transformer의 제품 dependency 채택을 **reject**한다. 필요한 동작보다 extras와 serializer dependency가 넓고, Cue strict wrapper가 이미 더 작은 계약을 직접 제공하기 때문이다. 이는 TeamAI 전체의 품질 판정이나 향후 다른 범위에서의 재검토 금지가 아니다. 기존 TeamAI 관찰과 미실행 사실은 위 역사 기록에 그대로 남긴다.
