# Issue SLA (Cue)

Maintainer response targets for public issues and PRs on [zenovis2-create/cue](https://github.com/zenovis2-create/cue).

| Class | Target |
| --- | --- |
| First human response | within **24 hours** |
| Labels applied | within **48 hours** |
| **critical** (cannot install or start) | **same calendar day** (Asia/Seoul) |

## Labels (minimum set)

| Label | Use |
| --- | --- |
| `bug` | Incorrect behavior after install/start |
| `install` | Clone / `npm ci` / build / first launch failures |
| `question` | How it works / fit — not a defect |
| `enhancement` | Feature request in OSS scope |
| `critical` | Completely blocked: cannot install or start |

Additional labels (e.g. `good first issue`) may be added later.

## KPI note

Campaign KPI **issues/PRs (15)** and **external repros (5)** count **external** reports only. Maintainer/self-filed issues do not count. External repros must use the report fields in [EXTERNAL_REPRODUCTION.md](EXTERNAL_REPRODUCTION.md) (or the **External reproduction** issue form).

## Forms

Issue forms live under `.github/ISSUE_TEMPLATE/`. Blank issues are disabled; the reproduction guide is linked from the template chooser.
